# Rivelle CLI

Rivelle installs editable, themeable React and Next.js component source into your application.

```bash
pnpm dlx rivelle@latest init
pnpm dlx rivelle@latest add button

# Non-interactive Prism setup
pnpm dlx rivelle@latest init --yes --style prism
```

Foundational components are written to `components/ui`, expressive effects to `components/effects`, and application blocks to `components/blocks`. All generated source remains fully owned by the consuming project. Read the [documentation](https://rivelle.dev) or contribute at [w3cproject/rivelle-ui](https://github.com/w3cproject/rivelle-ui).
